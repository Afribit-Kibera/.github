# Afribit Builders

**Community software, built from Kibera.**

[Afribit Africa](https://afribit.africa) | [Builders](https://afribit.africa/builders) | [Tools](https://tools.afribit.africa) | [Contact](https://afribit.africa/contact)

We build tools for the work around a Bitcoin circular economy: recording waste collection, preparing Lightning payments, mapping merchants and supporting locally operated networks. Afribit-Kibera is the engineering organisation of [Afribit Africa](https://github.com/Afribit-Africa).

## Explore the Projects

### Taka Sats

Collection records, scale and photo evidence, offline capture and Lightning payout controls for community waste work.

[Source](https://github.com/Afribit-Kibera/taka-sats) | [Documentation](https://taka.afribit.africa/docs)

### Afribitools

Fastlight Lightning-address validation, payment-list exports and batch-payment tools. The repository also contains CBAF community-fund workflows.

[Source](https://github.com/Afribit-Kibera/tools) | [Open the app](https://tools.afribit.africa)

### BTCReg

Merchant registration, GPS capture, verification and reviewed publication to OpenStreetMap for discovery through BTC Map.

[Source](https://github.com/Afribit-Kibera/bitmap) | [Open the app](https://register.afribit.africa)

### 3 West Satenet Tools

Portal, payment and network-management software supporting a community-run network. Repository: `Afribit-Wifi`.

[Source](https://github.com/Afribit-Kibera/Afribit-Wifi) | [Community portal](https://wifi.afribit.africa)

### Afribit Website & Studio

Our public website, merchant directory, project pages and Bitcoin audio education with synchronised text.

[Source](https://github.com/Afribit-Kibera/Website) | [Website](https://afribit.africa) | [Bitcoin Studio](https://afribit.africa/studio)

## Experimental Projects

- **[Afribit Pay](https://github.com/Afribit-Kibera/afribit-wallet):** pre-launch wallet work based on Blink, exploring Bitcoin and M-Pesa payments. The repository retains its upstream relationship and credits.
- **[Afribit NFC](https://github.com/Afribit-Kibera/nfc):** a React Native and backend prototype for contactless card setup with NTAG424 and BTCPay Server integrations.

## Built Around Local Work

- **Field conditions:** simple mobile workflows and offline capture where the project supports it.
- **Payments:** clear records and explicit operator approval around actions that move funds.
- **Community ownership:** local operators make network decisions; Afribit contributes tools and technical support.
- **Useful records:** evidence that collection teams, merchants and programme organisers can inspect.

The 3 West Satenet tools are being piloted with local operators. Afribit is not an internet service provider. **Kibera Mesh** is a research track for local calling and chat, not a released communications service.
